# MiniFish v0.4 — браузер с профилями и фоновыми задачами

Личный браузерный помощник на Playwright + MCP: бесплатно без сторонних browser-API, но нужен сервер с Chromium. На телефоне открывается как веб-сайт, отдельный APK не требуется.

## Что работает

- Мобильная защищённая панель: вход, разрешение доменов, открыть страницу, назад, текст, элементы, ввод, клики, прокрутка, PNG.
- MCP endpoint `/mcp` с инструментами browser_open / snapshot / click / fill / select / scroll / back / screenshot / close. Для ChatGPT теперь есть OAuth 2.1 Authorization Code + PKCE (S256), регистрация клиента DCR с разрешёнными callback ChatGPT, короткоживущие токены и вход по паролю владельца. Прежний Bearer поддерживается для доверенных MCP-клиентов.
- Запрет URL без HTTPS, нестандартных портов и частных/служебных IP, в том числе для ресурсов страниц. Сессии временные, сохраняемых cookie/паролей нет.
- Для отправки форм и явно опасных кнопок через MCP требуется отдельное подтверждение.
- Прямой эфир `/live` с ручным управлением: касания экрана браузера с телефона, ввод текста/паролей и нажатия клавиш. Логин происходит напрямую через панель владельца, а не через ChatGPT.

## Развёртывание

Docker использует официальный образ браузера Playwright, в котором уже есть Chromium. Создайте отдельный проект с Dockerfile в Railway или Render. Настройте переменные:

| Переменная | Значение |
| --- | --- |
| `MINIFISH_PASSWORD` | Новый длинный пароль для входа владельца |
| `MINIFISH_SECRET` | Уникальная случайная строка длиной минимум 32 символа |
| `MINIFISH_MCP_TOKEN` | Другой случайный секрет для MCP (опционально, но без него MCP выключен) |
| `BROWSER_ALLOWED_DOMAINS` | `example.com` или доверенные сайты через запятую |
| `MINIFISH_PUBLIC_URL` | `https://nxval-minifish-2026.onrender.com` (без финального слеша) |
| `MCP_ALLOWED_HOSTS` | Домен веб-сервера (с маской порта, например `my-server.up.railway.app:*`) |
| `MCP_ALLOWED_ORIGINS` | `https://my-server.up.railway.app` |

Порт берётся из переменной `PORT`. Для подключения к ChatGPT в веб-версии откройте https://chatgpt.com/plugins → + → Add custom MCP server. Название `MiniFish`, URL `https://nxval-minifish-2026.onrender.com/mcp`, авторизация `OAuth` (динамическая регистрация/DCR). Создайте и установите плагин, откройте новый чат и выберите его через `@MiniFish`. При первом обращении откроется защищённая страница входа MiniFish с кнопкой подтверждения. Введите пароль владельца и нажмите «Разрешить подключение». Если интерфейс вашего аккаунта не поддерживает кастомные MCP, включить это изнутри MiniFish нельзя.

OAuth metadata: `/.well-known/oauth-authorization-server`, protected resource: `/.well-known/oauth-protected-resource`.

После развёртывания откройте корень HTTPS URL (без `/mcp`) в Chrome на Android. Пароль сохраняется в защищённой cookie на 7 дней. Добавляйте сайты через панель (в оперативной памяти до перезапуска).

Локально (только для разработки):

```sh
export MINIFISH_PASSWORD='use-long-unique-password'
export MINIFISH_SECRET='change-this-to-random-64-characters-in-production-123456789012'
export BROWSER_ALLOWED_DOMAINS='example.com'
export MINIFISH_LOCAL_HTTP=1
pip install -r requirements.txt
python -m playwright install chromium
uvicorn server:app --host 127.0.0.1 --port 8000
```

Затем зайдите на `http://127.0.0.1:8000`.

## Ручной вход в аккаунты через телефон

1. Откройте MiniFish в ChatGPT на разрешённом сайте и запустите браузерную сессию.
2. На телефоне войдите в панель владельца MiniFish и откройте `/live`.
3. Включите режим кликов и выберите поле логина или пароля на прямом эфире браузера.
4. Введите пароль в защищённом поле панели, а не в ChatGPT; нажмите «Ввести в браузер», затем при необходимости клавишу Enter.
5. После входа продолжите работу в ChatGPT с той же `session_id`. Cookie живут только в открытой сессии до её закрытия, истечения времени или перезапуска сервера. Функция не обходит CAPTCHA и двухфакторную проверку.

## Профили и фоновые задачи (v0.4)

- `browser_save_profile(session_id,name)` сохраняет cookies, localStorage и IndexedDB в **зашифрованном** виде, ключ выводится из `MINIFISH_SECRET`. Хранение паролей в явном виде не требуется. Авторизация на сайте должна быть выполнена владельцем в /live.
- `browser_profiles()` показывает имена и домены; `browser_open_profile(name,url)` восстанавливает сохранённую сессию на соответствующем домене, `browser_delete_profile(name)` удаляет профиль.
- `background_submit(url,steps,profile,run_at)` добавляет задачу в фоновую очередь. Поддерживает последовательные действия `goto`, `click`, `fill`, `select`, `scroll`, `wait`, `snapshot`. Каждая задача исполняется отдельной сессией без открытого чата. `background_jobs()` возвращает статусы, `background_cancel(job_id)` отменяет ожидающую задачу.
- Рабочий процесс ограничен 20 шагами, таймаутами, явно разрешёнными HTTPS-доменами; опасные кнопки, отправка форм, ввод паролей и произвольный JavaScript автоматически не разрешаются.
- Перезапуск сервера **не повторяет** уже выполнявшиеся шаги: незаконченная задача получает статус `interrupted`, чтобы не нажать опасную кнопку повторно.
- **Постоянное хранение требуется настроить отдельно.** Используйте `MINIFISH_DATABASE_URL` — отдельную PostgreSQL-базу с TLS, доступную только MiniFish. В ней создаются таблицы `mf_profiles` и `mf_jobs`. Требуются `MINIFISH_SECRET` длиной не менее 32 символов и безопасное хранение переменных окружения в Render. Альтернатива — постоянный диск с `MINIFISH_SQLITE_PATH` и `MINIFISH_PERSISTENT_DISK=1`, когда такой диск реально смонтирован. Не добавляйте URL базы или ключи в GitHub.
- Пока ни базы, ни диска нет, данные сохраняются в локальный SQLite — **только временно**. В бесплатном Render они пропадают после обновления/перезапуска. Панель и API честно показывают `durable=false`.
- Render Free может засыпать без запросов; фоновые задачи и расписание не работают в период сна. Для гарантированного выполнения по расписанию нужен постоянно работающий сервер или внешний планировщик; невозможно обещать 24/7 на Render Free.
- Фоновый движок не имеет собственного LLM: ChatGPT составляет набор шагов и запускает их, MiniFish исполняет. Если сайт меняется, шаг может завершиться ошибкой вместо непроверенного успеха.

## Ограничения

Это не TinyFish: **нет автономного серверного AI-планировщика**, работающего независимо от ChatGPT, платежей, фоновых задач и долгосрочного сохранения браузерных сессий. Ручной вход владельца реализован через `/live`. Панель позволяет управлять браузером вручную с телефона. Применять LLM для планирования можно через MCP-клиент, который поддерживает подключение с Bearer-токеном. Для подключения прямо в ChatGPT требуется возможность создавать пользовательские MCP-плагины в аккаунте; MiniFish поддерживает OAuth 2.1, но не может самостоятельно установить плагин в ChatGPT. Не публикуйте токены и не раскрывайте пароль.

Контейнерная песочница не является гарантией полной изоляции от зловредных сайтов. Для production требуется доп. жёсткая изоляция браузера на уровне хоста, внешние ограничения egress и централизованная rate limiting. Не обещается обход капч и защит сайтов.

Базовая проверка: `python -m pytest -q tests/`; для интеграции нужен реальный Chromium и хостинг.
